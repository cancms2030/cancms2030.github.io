## 主题简介

Anatole 是一款极简主义的双栏 Hugo 博客主题，以其干净的视觉设计和满分的 Google Lighthouse 性能评分而著称。左侧个人信息栏 + 右侧内容区的经典布局，既适合个人品牌展示，也适合日常博客写作。

## 核心特性

- **双栏布局**：左侧固定个人信息区（头像、简介、社交链接），右侧内容流
- **Lighthouse 满分**：性能、可访问性、最佳实践、SEO 四项指标均为 100 分
- **暗色模式**：支持亮色/暗色主题切换，自动跟随系统偏好
- **极简设计**：无多余装饰，专注于内容和阅读体验
- **响应式设计**：移动端自动切换为单栏布局
- **社交链接**：支持 GitHub、Twitter、LinkedIn 等主流平台
- **文章分类与标签**：灵活的 taxonomy 支持
- **代码高亮**：内置语法高亮
- **SEO 友好**：完整的 Open Graph 和 Twitter Cards 标签
- **轻量快速**：零 JavaScript 框架依赖，纯 CSS 实现所有样式

## 适用场景

- 个人博客
- 开发者/设计师个人主页
- 技术写作
- 极简风格爱好者
- 追求极致性能的网站

## 快速开始

```bash
# 克隆主题
git clone https://github.com/lxndrblz/anatole.git themes/anatole

# 在 config.toml 中设置
theme = "anatole"
```
