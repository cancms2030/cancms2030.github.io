## 主题简介

Hextra 是一款新一代的 Hugo 文档主题，基于 Tailwind CSS 构建，融合了现代 Web 设计理念。它不仅是一个出色的文档主题，还内置了博客功能，适合同时需要文档站和博客的团队或个人。其精美的设计和流畅的交互体验，使其成为近年来增长最快的 Hugo 文档主题之一。

## 核心特性

- **Tailwind CSS 驱动**：基于 utility-first CSS 框架，样式高度可定制
- **文档+博客双模式**：同一站点可同时承载文档和博客内容
- **全文搜索**：内置 FlexSearch 全文搜索引擎，响应迅速
- **暗色模式**：跟随系统偏好或手动切换，过渡动画流畅
- **侧边栏导航**：自动生成的多级目录，支持折叠展开
- **多语言支持**：完善的 i18n 国际化机制
- **代码高亮与复制**：语法高亮 + 一键复制按钮
- **KaTeX 数学公式**：支持 LaTeX 数学公式渲染
- **SEO 友好**：完善的 Open Graph、Twitter Cards 和 JSON-LD 结构化数据

## 适用场景

- 技术文档 + 博客一体化站点
- 开源项目文档
- 个人技术博客与知识库
- 产品帮助中心
- 学习笔记与教程站

## 快速开始

```bash
# 作为 Hugo Module 引入（推荐）
hugo mod get github.com/imfing/hextra

# 在 hugo.toml 中配置
[module]
  [[module.imports]]
    path = "github.com/imfing/hextra"
```

## 推荐理由

Hextra 代表了 Hugo 文档主题的新方向——更现代的设计、更好的性能和更灵活的用途。如果你希望文档站点拥有现代化的视觉体验，或者需要在同一站点中兼顾文档和博客两种内容形式，Hextra 是当前最佳选择。其基于 Tailwind CSS 的架构也使得二次开发和样式定制变得更加简单高效。
