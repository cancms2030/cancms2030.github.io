Hugo Profile

主题简介

Hugo Profile 是一款专为个人作品集和在线简历设计的 Hugo 主题，采用移动优先的设计理念，确保在各种设备上都有出色的展示效果。它提供了完整的作品集展示、技能图表、项目经历等模块，是求职者和自由职业者打造个人品牌的理想选择。

核心特性

  • 移动优先设计：从移动端开始设计，逐步增强桌面端体验
  • 作品集展示：内置项目卡片组件，支持图片、描述、链接和技术标签
  • 技能展示：支持进度条和技能标签两种展示方式
  • 时间线组件：用于展示工作经历、教育背景等时间线内容
  • 暗色模式：支持亮色/暗色主题切换
  • 多语言支持：完善的 i18n 国际化机制
  • 社交链接：支持主流社交平台图标和链接
  • 联系表单：集成 Formspree 等第三方表单服务
  • SEO 优化：完整的结构化数据和 Open Graph 标签
  • 轻量快速：无重型框架依赖，加载速度极快

适用场景

  • 求职者在线简历
  • 自由职业者作品展示
  • 开发者个人主页
  • 设计师作品集
  • 毕业生求职页面

快速开始

# 克隆主题
git clone https://github.com/gurusabarish/hugo-profile.git themes/hugo-profile

# 在 config.toml 中设置
theme = "hugo-profile"

推荐理由

Hugo Profile 专注于"展示个人"这一核心需求，所有功能都围绕作品集和简历展开。相比通用型主题，它的配置更直观、模块更聚焦，特别适合需要在短时间内搭建一个专业个人页面的用户。移动优先的设计也确保了在手机端的完美展示，这在招聘场景中尤为重要。
