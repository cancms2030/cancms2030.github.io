Blowfish

主题简介

Blowfish 是一款基于 Tailwind CSS 构建的功能强大的 Hugo 个人主题，专为个人品牌展示、作品集和技术博客设计。它提供了极其丰富的配置选项和组件库，让你无需编写任何代码就能打造出专业级的个人网站。

核心特性

  • Tailwind CSS 驱动：完全基于 utility-first CSS 框架，样式高度可定制
  • 暗色模式：自动跟随系统偏好或手动切换，过渡动画流畅自然
  • 多语言支持：完善的 i18n 国际化机制，支持 20+ 种语言
  • 图片画廊：内置响应式图片画廊组件，支持灯箱效果
  • SEO 优化：完整的 Open Graph、Twitter Cards、JSON-LD 结构化数据
  • 丰富短代码：徽章、按钮、图标、提示框、时间线等 20+ 种组件
  • 文章系列：支持将多篇文章组织为系列，自动导航
  • 作者信息：支持多作者模式，每位作者有独立头像和简介
  • 搜索功能：内置 Fuse.js 全文搜索
  • 评论系统：支持 Disqus、Giscus、Utterances 等多种评论方案

适用场景

  • 个人品牌官方网站
  • 设计师/开发者作品集
  • 技术博客与知识分享
  • 自由职业者服务展示
  • 学术研究者主页

快速开始

# 作为 Hugo Module 引入（推荐）
hugo mod get github.com/nunocoracao/blowfish/v2

# 在 hugo.toml 中配置
[module]
  [[module.imports]]
    path = "github.com/nunocoracao/blowfish/v2"

推荐理由

Blowfish 是目前功能最全面的 Hugo 个人主题之一，其基于 Tailwind CSS 的架构使得样式定制变得异常简单。无论你是想搭建一个简洁的个人简历页，还是一个内容丰富的技术博客，Blowfish 都能通过配置而非编码来满足需求。活跃的社区和频繁的更新也确保了主题的长期可用性。
