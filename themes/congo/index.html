Congo

主题简介

Congo 是一款基于 Tailwind CSS 构建的现代简约 Hugo 主题，专为个人品牌和作品集展示设计。它在保持轻量的同时提供了丰富的功能，以"少即是多"的设计哲学打造出既美观又高效的个人网站。

核心特性

  • Tailwind CSS 驱动：完全可定制的配色方案和排版样式
  • 暗色模式：自动检测系统偏好，支持手动切换
  • 多语言支持：内置 i18n 国际化，支持多种语言
  • 响应式设计：完美适配所有设备尺寸
  • SEO 友好：完整的 Open Graph、Twitter Cards 和 Schema.org 结构化数据
  • 文章分类与标签：灵活的分类体系，支持自定义 taxonomy
  • 代码高亮：内置语法高亮，支持行号和复制按钮
  • 图片优化：自动处理响应式图片和懒加载
  • 社交链接：支持 50+ 种社交平台图标
  • 零 JavaScript 依赖：核心功能无需 JS，极致性能

适用场景

  • 个人品牌官方网站
  • 开发者/设计师简历页
  • 技术博客
  • 自由职业者作品展示
  • minimalist 风格爱好者

快速开始

# 作为 Hugo Module 引入（推荐）
hugo mod get github.com/jpanther/congo/v2

# 在 hugo.toml 中配置
[module]
  [[module.imports]]
    path = "github.com/jpanther/congo/v2"

推荐理由

Congo 在功能丰富与极简设计之间找到了完美的平衡点。相比 Blowfish 的全面，Congo 更注重"恰到好处"——它提供了个人品牌站所需的所有核心功能，同时保持了代码的简洁和加载的极速。如果你追求现代感但不喜欢过度设计，Congo 是理想选择。
