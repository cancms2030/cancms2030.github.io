Docket

主题简介

Docket 是一款追求极致简洁的 Hugo 文档主题，摒弃了一切不必要的装饰和功能，将注意力完全聚焦于内容本身。对于不需要复杂功能、只想快速搭建一个干净文档站点的开发者来说，Docket 提供了一个零负担的选择。

核心特性

  • 极简设计：无多余装饰，纯净的阅读体验
  • 零配置启动：开箱即用，无需复杂配置即可生成文档站
  • 语义化 HTML：良好的可访问性和 SEO 基础
  • 响应式布局：适配各种屏幕尺寸
  • 代码高亮：内置语法高亮支持
  • 轻量级：极小的 CSS/JS 体积，加载速度极快
  • 易于定制：简洁的代码结构，方便二次开发

适用场景

  • 小型开源项目文档
  • API 参考手册
  • 个人技术笔记与知识库
  • 内部工具使用说明
  • 快速原型文档

快速开始

# 克隆主题
git clone https://github.com/refactorian/docket.git themes/docket

# 在 config.toml 中设置
theme = "docket"

推荐理由

Docket 适合那些"只需要一个好用的文档页面"的场景。当你的项目规模不大、不需要版本管理和多语言等高级功能时，Docket 的极简哲学反而是一种优势——没有学习成本、没有配置负担、没有性能浪费。它也适合作为自定义文档主题的起点，在其简洁的代码基础上进行二次开发。
