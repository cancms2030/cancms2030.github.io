Hugo Eureka

主题简介

Hugo Eureka 是一款由中文开发者维护的 Hugo 主题，兼具个人品牌展示和技术写作功能。其设计优雅专业，在视觉美感和内容可读性之间取得了良好平衡，特别适合希望同时展示个人品牌和发表技术文章的创作者。

核心特性

  • 优雅设计：精心设计的排版和配色，视觉效果专业大气
  • 暗色模式：支持亮色/暗色主题自动切换
  • 多语言支持：完善的 i18n 国际化机制，中英文无缝切换
  • 响应式布局：完美适配桌面端、平板和移动设备
  • SEO 优化：完整的 Open Graph、Twitter Cards 和结构化数据
  • 文章目录：自动生成的文章目录，支持滚动高亮
  • 代码高亮：内置语法高亮，支持多种编程语言
  • 数学公式：支持 KaTeX 数学公式渲染
  • 评论系统：支持 Disqus、Giscus 等多种评论方案
  • 社交链接：支持主流社交平台图标

适用场景

  • 技术博主个人主页
  • 研究者/学者学术主页
  • 自由职业者品牌展示
  • 中文技术写作
  • 个人博客与作品集

快速开始

# 克隆主题
git clone https://github.com/wangchucheng/hugo-eureka.git themes/hugo-eureka

# 在 config.toml 中设置
theme = "hugo-eureka"

推荐理由

Hugo Eureka 由中文开发者打造，对中文排版和内容展示有天然的优化优势。如果你是一位中文技术创作者，希望拥有一个既能展示个人品牌又能发表深度技术文章的网站，Eureka 是一个值得考虑的选择。其优雅的视觉设计和完善的功能配置，能够满足大多数个人品牌站的需求。
