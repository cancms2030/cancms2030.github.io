## 主题简介

Hugo Theme Learn 是最早流行的 Hugo 文档主题之一，完美复刻了 GitBook 的经典阅读体验。其直观的侧边栏导航、清晰的章节结构和丰富的短代码支持，使其成为构建产品手册、培训资料和学习指南的理想选择。

## 核心特性

- **GitBook 经典风格**：熟悉的左侧目录 + 右侧内容布局，用户零学习成本
- **多级目录导航**：支持无限层级的章节嵌套，自动高亮当前阅读位置
- **全文搜索**：内置基于 Lunr.js 的客户端搜索，无需后端服务
- **多语言支持**：完善的 i18n 机制，支持中英文及更多语言
- **丰富短代码**：内置提示框、标签页、按钮、图标等实用短代码
- **Mermaid 图表**：支持流程图、时序图等可视化内容
- **打印友好**：优化的打印样式，方便导出 PDF
- **响应式设计**：适配桌面端和移动设备

## 适用场景

- 产品使用手册
- 内部培训资料
- 在线教程与学习指南
- 知识库与帮助文档
- 技术入门指南

## 快速开始

```bash
# 克隆主题到 themes 目录
git clone https://github.com/matcornic/hugo-theme-learn.git themes/hugo-theme-learn

# 在 config.toml 中设置
theme = "hugo-theme-learn"
```

## 推荐理由

Hugo Theme Learn 以其经典的 GitBook 风格和极低的上手门槛，特别适合需要快速搭建文档站点的团队。如果你的用户群体熟悉 GitBook 的阅读体验，或者你需要构建面向非技术人员的培训资料和教程，Learn 主题是最佳选择。虽然项目维护频率有所降低，但其稳定性和成熟度仍然值得信赖。
