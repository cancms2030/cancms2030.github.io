## 主题简介

Dimension 是一款以全屏视觉风格为核心的单页作品集主题。其设计灵感来源于现代网页设计的趋势——利用大幅背景图片和大胆的排版，在访客打开页面的瞬间创造强烈的视觉冲击力。适合摄影师、设计师、艺术家等创意工作者展示个人品牌。

## 核心特性

- **全屏背景**：支持高分辨率背景图片，营造沉浸式体验
- **大胆排版**：醒目的标题字体，强化视觉层次
- **单页架构**：所有内容集中在一个页面，通过平滑滚动导航
- **响应式设计**：针对不同屏幕尺寸优化布局和字体大小
- **社交链接**：底部社交图标，扩展个人影响力
- **联系表单**：集成联系功能，方便潜在客户沟通
- **轻量级**：极简的代码结构，确保快速加载

## 适用场景

- 摄影师作品集
- 平面设计师个人网站
- 艺术家在线画廊
- 创意总监个人品牌页
- 自由职业者展示页

## 快速开始

```bash
# 克隆主题
git clone https://github.com/digitalcraftsman/hugo-dimension-theme.git themes/dimension

# 在 config.toml 中设置
theme = "dimension"
```

## 推荐理由

Dimension 以其独特的全屏视觉风格，在众多 Hugo 主题中脱颖而出。如果你是一位视觉创意工作者，希望用最具冲击力的方式展示作品，Dimension 是理想选择。其设计哲学是"让作品说话"——减少干扰元素，让访客的注意力完全聚焦于你的创意成果。
